## Publish with GitHub Pages

1. Sign in to GitHub and create a public repository named `momo-sms`. Do not initialize it with a README, license, or gitignore if pushing this existing local repository.
2. Push the local `main` branch to that repository, or upload the four files into the repository root using GitHub's upload interface.
3. Open repository **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/ (root)**, and click **Save**.
6. Wait until GitHub Pages reports a successful deployment. Use its **Visit site** link.
7. On that site, open `privacy.html` and `terms.html` directly. Copy the resulting public HTTPS URLs into the corresponding Twilio A2P campaign fields.

Relative links work when the site is hosted under the `/momo-sms/` project path. No build command or package installation is required.
